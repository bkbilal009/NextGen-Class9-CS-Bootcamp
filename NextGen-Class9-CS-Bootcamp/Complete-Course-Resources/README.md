# 🚀 Class 9 Computer Science Bootcamp

### 💻 2-Month Intensive Program (2025–2026)

---

## 📌 Program Overview

A structured **2-month Computer Science program** designed for Class 9 students, aligned with the academic curriculum.
Focused on building **strong foundations** and advancing towards **practical skills in programming, web development, and modern technologies**.

---

## 🎯 Objectives

✔ Build strong core computer science concepts
✔ Develop problem-solving & computational thinking
✔ Introduce real-world tools & technologies
✔ Provide hands-on programming experience
✔ Prepare students for future tech careers

---

## ⏳ Course Details

* 📅 Duration: 8 Weeks (2 Months)
* 🎓 Level: Class 9
* 💻 Subject: Computer Science

### 🗓️ Schedule

* Mon–Thu: Teaching
* Friday: Assessment / Quiz
* Saturday: Revision / Practice

---

## 📚 Curriculum Overview

### 🔹 Month 1 — Foundations

**Week 1**

* Introduction to Systems
* Number Systems
* Digital Logic & Gates

**Week 2**

* Troubleshooting
* Software Systems

**Week 3**

* Computer Networks
* OSI Model & Protocols

**Week 4**

* Computational Thinking
* Algorithms & Flowcharts
* Dry Run & LARP

---

### 🔹 Month 2 — Practical Skills

**Week 5**

* HTML & CSS
* JavaScript Basics

**Week 6**

* Python Programming
* Data Science Intro

**Week 7**

* Emerging Technologies (AI, IoT, Cloud)
* Ethics & Digital Safety
* Entrepreneurship

**Week 8**

* Revision
* Practical Work
* Final Project
