# 📘 Month 01 – Foundations & Core Concepts

## 🚀 Building Strong Computer Science Foundations

---

## 📌 Overview

This section covers the **first month** of the Class 9 Computer Science Bootcamp.
The focus is on developing **core concepts and logical understanding** that form the base for advanced topics.

---

## 🎯 Learning Goals

✔ Understand computer systems and how they work
✔ Master number system conversions
✔ Learn digital logic fundamentals
✔ Identify and solve system issues
✔ Understand basic networking concepts
✔ Develop computational thinking skills

---

## 📚 Weekly Breakdown

### 🔹 Week 01 — Introduction & Number Systems

* Computer Systems & IPO Model
* Binary, Octal, Hexadecimal Conversions
* Digital Logic & Basic Gates

---

### 🔹 Week 02 — Troubleshooting & Software

* System Troubleshooting Techniques
* Types of Software
* Operating Systems Overview

---

### 🔹 Week 03 — Computer Networks

* Network Topologies
* OSI Model (7 Layers)
* Protocols & Network Services

---

### 🔹 Week 04 — Algorithms & Thinking

* Computational Thinking
* Algorithms & Flowcharts
* Pseudocode & Dry Run
* Introduction to LARP

---

## 🧪 Assessments

✔ Weekly Quizzes
✔ Practice Worksheets
✔ Mid-Term Evaluation (Week 4)

---

## 🛠️ Activities

* Number system practice
* Logic gate diagrams
* Network diagrams
* Pseudocode writing
* Algorithm dry runs

---

## 📈 Outcomes

By the end of Month 1, students will:

* ✔ Build strong theoretical foundations
* ✔ Improve logical thinking
* ✔ Understand key CS concepts
* ✔ Prepare for practical implementation

---

## 🌟 Note

This phase is the **foundation of the entire course**, ensuring students are ready for practical and advanced topics in Month 2.
