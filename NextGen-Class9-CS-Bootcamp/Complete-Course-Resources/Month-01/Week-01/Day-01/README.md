# 📘 Day 01 – Introduction to Systems

## 🚀 Understanding How Systems Work

---

## 📌 Overview

Day 01 focuses on introducing students to the concept of **systems** and how they function in everyday life and in computing.

---

## 🎯 Learning Objectives

✔ Understand what a system is
✔ Identify different types of systems
✔ Recognize components of a computer system
✔ Understand the IPO (Input-Process-Output) model

---

## 📚 Topics Covered

* What is a System?
* Types of Systems (Natural & Man-Made)
* Computer System Components
* Input → Process → Output Model

---

## 🛠️ Activities

* Class discussion on real-life systems
* Identify input, process, and output in examples
* Draw IPO diagrams

---

## 💡 Examples

* Washing Machine as a system
* Computer as an input-output system

---

## 📈 Learning Outcome

By the end of this session, students will:

* ✔ Understand the concept of systems
* ✔ Explain IPO model with examples
* ✔ Relate computer systems to real-world systems

---

## 🌟 Note

This session builds the **base understanding** required for all future computer science topics.
