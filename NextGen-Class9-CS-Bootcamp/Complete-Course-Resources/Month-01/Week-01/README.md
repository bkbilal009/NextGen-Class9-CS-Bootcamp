# 📅 Week 01 – Introduction & Number Systems

## 🚀 Starting the Computer Science Journey

---

## 📌 Overview

This week introduces students to the **fundamentals of computer science**, including system concepts and number systems.
It builds the foundation for understanding how computers process and represent data.

---

## 🎯 Learning Objectives

✔ Understand what a system is
✔ Learn components of a computer system
✔ Understand the Input-Process-Output (IPO) model
✔ Perform number system conversions
✔ Get introduced to digital logic

---

## 📚 Topics Covered

### 🔹 Day 1–2

* Introduction to Systems
* Types of Systems
* Computer System Components
* IPO Model

---

### 🔹 Day 3–4

* Decimal to Binary Conversion
* Decimal to Octal Conversion
* Decimal to Hexadecimal Conversion

---

### 🔹 Saturday (Extra)

* Introduction to Digital Logic
* Basic Logic Gates (AND, OR, NOT)
* Truth Tables

---

## 🧪 Assessment

* Quiz on Number Systems
* Short Q&A on IPO Model

---

## 🛠️ Activities

* Class discussion on systems
* Practice worksheets (number conversions)
* Logic gate diagrams
* Truth table exercises

---

## 📈 Outcomes

By the end of this week, students will:

* ✔ Understand basic system concepts
* ✔ Perform number conversions confidently
* ✔ Understand basic logic gates

---

## 🌟 Note

This week lays the **core foundation** for all upcoming topics in computer science.
